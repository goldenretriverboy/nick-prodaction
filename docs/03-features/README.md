# 03: Features

Раздел для прикладной документации по пользовательским сценариям и страницам.

## План наполнения

- Главная страница (`/`): hero, блок работ, тарифы, форма.
- Страница работ (`/works`): список кейсов, пагинация, empty/error states.
- Интеграции API: earnings, works, tariffs, leads.

По мере реализации каждая фича получает отдельный документ с контрактами, edge-cases и тест-кейсами.
